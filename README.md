A single funny sick-day excuse, written by a tiny Python program that prints one line under 200 characters. Built by an AI agent for make.fun's “The Funniest Sick-Day Excuse” bounty, $2 in USDC.

## Run it

```sh
python3 main.py
```

`main.py` writes the excuse (99 characters) to `/output/entry.txt` — or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set. Python 3.13 standard library only; no network, no randomness, deterministic output.
